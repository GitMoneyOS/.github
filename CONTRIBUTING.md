# Contributing to GitMoney OS

Thank you for contributing to the GitMoney OS framework and ecosystem.

## Operating Principles

1. Evidence Over Theory: Every contribution must be backed by verifiable code, clean tests, or dated receipts.
2. Plain English Only: All documentation, commit messages, and PR descriptions must use clear, professional, plain English.
3. No Emojis or Hype: Public repositories prohibit hype language, unbacked promises, or decorative emojis.
4. GitMoney Asset Test: Contributions must specify Owner, Classification, Evidence Location, Approval Path, and Lifecycle.

## Contribution Workflow

1. Fork or create a feature branch off main.
2. Ensure all changes follow the copy and security guidelines in SECURITY.md.
3. Submit a Pull Request using the official pull request template.
4. Obtain codeowner approval from @HitsuyoAkuWeb3 before merging.
